# منظومة إتقان — نموذج أولي لإدارة المدارس

نموذج أولي تفاعلي (Prototype) لنظام إدارة مدارس باللغة العربية.

**رابط العرض:** https://fabusafiyah.github.io/Madrasati/

## الشاشات
- لوحة القيادة
- المستخدمون والصلاحيات
- الصفوف والشعب
- الجداول والحصص
- الحضور والانصراف
- الغياب والبدلاء التلقائي (تفاعلي)
- الحصة المباشرة (تفاعلي)
- آلية التعيين التلقائي
- تطبيق المعلم: بدء الحصة، وإشعار تكليف الاحتياط (تفاعلي)

صفحات HTML ثابتة بدون أي خطوات بناء، تعمل مباشرة على GitHub Pages.
الأسماء والأرقام بيانات تجريبية.
